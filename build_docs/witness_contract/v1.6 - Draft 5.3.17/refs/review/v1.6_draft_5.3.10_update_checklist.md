# Duotronics v1.6 — Draft 5.3.10 Update Checklist

## P0 — Database and key-lifecycle correctness

### 1. Close SQLite connections on every `_connect()` failure
- Wrap post-open setup and schema verification in `try/except`.
- Close before re-raising.
- Test quick-check, version, schema, and file-security failures.
- Require a clean Python 3.13 warning-as-error run.

### 2. Verify the exact SQLite schema
- Compare normalized table and index SQL.
- Verify table affinities, NOT NULL, defaults, checks, and PK order.
- Verify index column order, uniqueness, partial predicates, and origin.
- Reject all extra triggers, views, and virtual objects.
- Bind a canonical schema digest to migration metadata.
- Add weakened-schema adversarial fixtures.

### 3. Enforce cache-signing key lifecycle
- Add date-time format to non-null `valid_until`.
- Enforce `valid_from <= now < valid_until`.
- Enforce status and revocation.
- Validate rotation predecessors and reject cycles.
- Define replay behavior for retired and revoked keys.
- Record the registry snapshot and validity decision.

## P1 — Complete request lifecycle

### 4. Enforce the deadline through final publication
- Check before/after witness signing.
- Check before/after cache-envelope signing.
- Check before final lease renewal.
- Check before/after SQLite completion.
- Derive SQLite busy timeout from remaining time.
- Bind final elapsed time and remaining budget.

### 5. Recompute internal compile commands in the trusted domain
- Reconstruct expected Lean argv per module.
- Compare every command digest.
- Reject extra, missing, reordered, or altered commands.
- Verify warning-as-error and environment identities independently.

### 6. Stress-test lease renewal
- Very short leases.
- Slow database writes.
- Delayed heartbeat scheduling.
- Lease loss during signing.
- Worker restart and process pause.
- Ensure lost owners cannot publish.

- No SQLite handle leaks on any failure path.
- Weakened SQLite schemas are rejected.
- Active cache key is time-valid and rotation-valid.
- The request deadline covers signing and durable publication.
- Trusted consumer recomputes every internal Lean command digest.
