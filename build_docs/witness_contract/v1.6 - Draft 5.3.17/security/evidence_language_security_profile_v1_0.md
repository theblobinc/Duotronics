# Evidence Language Security Profile v1.0

## Threats

- authority laundering through repeated audit claims,
- theorem laundering through computational evidence,
- replay confusion through missing assumptions,
- delegation scope expansion,
- non-deterministic verification grammar,
- deep-time misinterpretation,
- NLA explanation mistaken for fact.

## Controls

- fail-closed policy evaluation,
- non-collapse constraint,
- deterministic verification grammar,
- explicit force indicators,
- hashed replay assumption manifests,
- scope-bounded delegation chains,
- no automatic model promotion,
- raw activation redaction.
