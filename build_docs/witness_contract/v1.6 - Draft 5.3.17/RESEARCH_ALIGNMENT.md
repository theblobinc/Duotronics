# Research alignment

This profile was designed against repository commit `7a92ad713892f63fac280a884a4ad1959dc148ac` and the newest relevant Duotronics works present there.

## Applied ideas

- **SRNN Cognition Architecture, Part VI:** preserves the two-level split between canonical object witness `W_t` and recurrent witness state `W~_t`. The contract keeps cryptographic attestation as a third, independent layer.
- **SRNN Cognition Architecture, Part VII:** adopts binary search signatures as non-authoritative first-pass retrieval sidecars; keeps float or richer witness reranking; treats meta-object relations as the connective fabric; supports typed sparse graph edges and compressed recurrent traces.
- **A Zero-Free Tensor Framework for Analog Computing - The Duotronic Hexagonal Grid** (July 2, 2026): uses positive-baseline, typed tensor and graph concepts for runtime state and diagnostics, but not as a cryptographic primitive. The paper itself identifies hardware and experimental limitations, so its math cannot responsibly replace standardized security constructions.
- **The Duotronics Framework - Discrete-State Processing as a Computational Regime in Biological and Artificial Cognition, rev-4.3:** preserves deterministic anchors, replayability, fail-closed authority, and non-collapse semantics.

## Factoring paper boundary

The reviewed quantum factoring paper informs the producer/verifier split: probabilistic or heuristic discovery produces a candidate, while a deterministic certificate verifier establishes correctness. It does not define a faster signature, hash, KEM, encryption mode, or meta-object matching algorithm and therefore is not used as one.

## Design boundary

Duotronic mathematics shapes canonical objects, graph relations, recurrent witness state, retrieval, diagnostics, and evidence separation. Standardized cryptography protects those objects. This boundary avoids presenting unreviewed project-specific math as cryptographic security.
