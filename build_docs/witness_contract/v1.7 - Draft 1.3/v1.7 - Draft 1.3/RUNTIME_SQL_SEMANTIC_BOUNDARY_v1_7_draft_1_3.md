# Runtime SQL Semantic Boundary - v1.7 Draft 1.3

Draft 1.3 makes the SQL contract explicit. SQL is a persistence layer and coarse guard for first-class witness records. It persists every required active schema field, enforces foreign-key references where the corpus has stable object identifiers, checks enumerated scalar fields, and rejects simple unsafe promotions such as policyless Bayesian decision approval or proof-verified knot equivalence without proof references.

SQL is not, by itself, the semantic acceptance authority for JSON payload internals. The following MUST be validated by the Draft 1.3 validator or by logical observer kernel syscalls before a row is treated as accepted rather than merely stored:

- Bayesian distribution normalization and exact/log-space replay.
- Bayesian model-family/update-method compatibility.
- Typed knot encoding payload semantics.
- Braid generator bounds and zero-exponent policy.
- Knot authority-path replay and equivalence authority.
- Complete-invariant and proof-backed equivalence claims.
