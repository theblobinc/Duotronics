# Formal Language of Evidence Build Plan v1.0

## Phase A — corpus and schema groundwork

Add Draft 5.2 contracts, schemas, formal models, and validation suites.

## Phase B — datamodel introduction

Add Python dataclasses for claims, compound claims, inference witnesses, replay assumptions, verification grammar, delegation chains, and non-collapse states.

## Phase C — policy and replay upgrade

Add `CompositionPolicy`, `PragmaticConstraint`, and `NonCollapseConstraint`. Extend replay package with assumption manifests and verification grammar.

## Phase D — persistence and tests

Add additive tables and conformance tests.

## Phase E — runtime integration

Wire math, proof, NLA, truth observers, replay, and DBP envelopes into the evidence language.

## Phase F — deep-time hardening

Add deterministic verification grammar execution and deep-time replay tests.
