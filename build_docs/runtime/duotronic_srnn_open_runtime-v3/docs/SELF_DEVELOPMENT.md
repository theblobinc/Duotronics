# Self-Development Runtime Rules

The agentic self-development loop is intentionally candidate-only.

Allowed without external approval:

- inspect repository/corpus/runtime state
- create plan
- create isolated worktree
- patch candidate files
- run tests and conformance checks
- emit witness and diff summary

Requires external approval witness:

- merge
- deploy
- privileged operation
- production mutation
- use of secrets
- promotion of generated output to authority

Passing tests are evidence. They are not proof. A self-generated patch is a candidate. It is not a release.
